Privacy policy

Last updated: 18 October 2026

Who uses this app

Health Dashboard is a personal tool used only by its owner. It is not offered to the public, and no other person's data is collected.

What data it accesses

With the owner's consent, it requests read-only access to the owner's Google Health data (activity and fitness, health metrics and measurements, and sleep) and the owner's Withings measurements. It cannot create, change or delete any health data.

How the data is used and stored

  • Data is used only to display charts and summaries to the owner.
  • It is stored in the owner's private GitHub repository and on the owner's own devices.
  • Access tokens are stored as encrypted repository secrets or locally on the owner's computer.

Sharing

Data is never sold, shared with or transferred to third parties, and is not used for advertising, credit decisions or training of AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions (Google) or in the Withings account settings. Stored data can be deleted by removing it from the private repository.

Contact

Via the owner's GitHub profile: github.com/hkheria.
